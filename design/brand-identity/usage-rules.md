# KomunaID - Usage Rules

## Brand Identity Application

### Website / Frontend Public

1. **Header utama website**
   - Full logo horizontal di kiri atas navbar
   - Klik logo mengarah ke homepage

2. **Footer website**
   - Full logo + tagline singkat
   - Deskripsi singkat brand

3. **Homepage hero section**
   - Brand secara halus
   - Visual brand dengan warna palet resmi

4. **Halaman login/register**
   - Full logo di bagian atas form
   - Branding kuat namun clean

5. **Empty state / onboarding**
   - Simbol logo atau ilustrasi bergaya brand

### Dashboard

1. **Sidebar desktop (expanded)**
   - Full logo di bagian paling atas

2. **Sidebar desktop (collapsed)**
   - Simbol logo saja

3. **Topbar mobile**
   - Simbol + wordmark atau simbol saja

4. **Admin dashboard**
   - Branding KomunaID yang konsisten

### Browser / Sistem

1. **Favicon browser**
   - Simbol logo saja

2. **Web app icon**
   - Simbol logo

3. **Loading screen / splash**
   - Simbol logo dengan animasi ringan

### Dokumen & Komunikasi

1. **Email template**
   - Header email gunakan logo KomunaID

2. **PDF/export report**
   - Logo di header dokumen

3. **Halaman error (404/403/maintenance)**
   - Simbol atau logo kecil

## Visual Rules

### Warna
- Gunakan warna brand sebagai design tokens
- Konsisten di seluruh komponen
- Jangan campur warna di luar palet

### Tipografi
- Gunakan Poppins sebagai font utama
- Konsisten hierarchy
- Utamakan readability

### Komponen
- Gunakan komponen rounded modern, clean
- Banyak whitespace
- Card, badge, input, button, table, modal konsisten
- CTA utama: Blue / Navy
- Accent: Orange secukupnya
- Community/collaboration: Teal / Aqua

### States
Wajib ada:
- Loading state
- Empty state
- Error state
- Success state
- Access denied state
- 404 page
- 500 fallback yang branded
